配置说明

          
未配置或使用示例值时，工作台会用内置插画引擎离线出图，功能不受影响。

          

            
endpoint
请求地址

            
method
HTTP 方法

            
headers
请求头

            
body
JSON 请求体模板

            
responseImagePath
返回图片 URL 的路径

            
{{size}}
自动替换为「模型出图尺寸」，如 3200x1920

            
{{width}} {{height}}
分别替换为宽 / 高数值

            
useProxy
false = 浏览器直连（默认走本地代理）
