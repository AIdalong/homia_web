          IMAGE MODEL CONNECTION
          
配置生图 API

          
最终 Prompt 会注入请求体中的 {{prompt}} 占位符；手动创作上传的参考图可注入 {{image}}（未写该占位符时会自动补到 image 字段）。

        

      

      

        

          
连接配置 JSON

          
          

            
            
          

        

        

          
配置说明

          
未配置或使用示例值时，工作台会用内置插画引擎离线出图，功能不受影响。

          

            
endpoint
请求地址

            
method
HTTP 方法

            
headers
请求头

            
body
JSON 请求体模板

            
responseImagePath
返回图片 URL 的路径

            
{{size}}
自动替换为「模型出图尺寸」，如 2770x1662；已按接口的像素区间自动校正，可直接发给接口

            
{{width}} {{height}}
分别替换为出图宽 / 高数值（与 {{size}} 同源，供用 width / height 字段的接口）

            
{{image}}
手动创作上传的参考图（data URL，图生图用）；未写该占位符时会自动补到 image 字段

            
useProxy
false = 浏览器直连（默认走本地代理）
